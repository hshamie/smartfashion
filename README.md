# SmartFashionAI

## Run Locally

Start the API first:

```bash
cd SmartFashion.Api
dotnet run
```

The API listens on your Mac at:

```text
http://localhost:5161
http://192.168.0.108:5161
```

Then start the mobile app:

```bash
cd mobileapp
npm start
```

Use the Expo QR code for a phone on the same Wi-Fi network.

For native simulators:

```bash
npm run ios
npm run android
```

Swagger:

```text
http://localhost:5161/swagger
```
